# References

Raw source material the bundle's concepts were distilled from. Concepts cite
these files in their `sources` frontmatter; the files themselves are kept
verbatim (not edited) so claims can be re-checked.

- [Gitingest of w3c-cg/musicxml](sources/gitingest-w3c-cg-musicxml-8a5edab282632443.txt) - Full-text dump (via gitingest.com) of the MusicXML standard repo: tutorials, per-element examples, schemas, and test files. Distilled into [MusicXML](/musicxml/index.md).
- [Gitingest of BleuBleu/FamiStudio](sources/gitingest-bleubleu-famistudio-8a5edab282632443.txt) - Full-text dump (via gitingest.com) of the FamiStudio repo: user docs, format-relevant source, CLI, and sound-engine docs. Distilled into [FamiStudio](/famistudio/index.md). Note: this dump omits some core model classes (Project/Song/Channel) — see [FamiStudio overview](/famistudio/famistudio-overview.md).
